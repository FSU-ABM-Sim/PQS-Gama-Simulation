## Gama-Project ready for import. <br/>
Currently, two models are available<br/>
### single run simulation: <br/>
- Adjust the amount of agents (line 29-33) <br/>
- Always choose the appropriate shapefile (line 21-27) to handle the assigned agents <br/>
- Set starting values to your liking; specified in the organisation-specific species.<br/>
  - Current starting values are set at random.<br/>
### multi simulation: <br/>
- The number of simulations needs to be adjusted based on needs (line 1023) <br/>
  - If running a high amount of simulations, make sure you have made enough RAM available to GAMA <br/>
  - Each Simulation will generate its own output file in the form of CSV <br/>
- Set starting values to your liking; specified in the organisation-specific species.<br/>
  - Current starting values are set at random.<br/>
